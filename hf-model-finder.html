HF Model Finder

Type it the way you'd say it: gemma 4 26b gguf, qwen3 coder 30b mlx 4bit, llama 3.1 8b q4_k_m by bartowski -abliterated

Tips & options

Name words must all appear in the repo name. A number right after a word is treated as its version (gemma 4 matches gemma-4, gemma4, Gemma_4 but not gemma-3-4b). Sizes like 26b, 1.5b, e4b, 135m match exactly, so 4b won't match a4b or 14b. Exclude words with -word or not word. Set an author with by name or name/model. Quant filters check the actual file names in the repo, so q4_k_m only shows repos that ship that file.

Loose matching lets name words match inside other words (e.g. gemma also hits medgemma).
