HF Model Finder

Type it the way you'd say it: gemma 4 26b gguf, qwen3 coder 30b mlx 4bit, llama 3.1 8b q4_k_m by bartowski -abliterated, gemma 4 31b radiance w4a8 mtp, radiance containers

Tips & options

Name words must all appear in the repo name. A number right after a word is treated as its version (gemma 4 matches gemma-4, gemma4, Gemma_4 but not gemma-3-4b). Sizes like 26b, 1.5b, e4b, 135m match exactly, so 4b won't match a4b or 14b. Exclude words with -word or not word. Set an author with by name or name/model. Quant filters check the actual file names in the repo, so q4_k_m only shows repos that ship that file.

Loose matching lets name words match inside other words (e.g. gemma also hits medgemma).

Radiance: add radiance or rad to the query (or pick it under Format). Only repos that actually ship a .rad container are shown, so vLLM-radiance wheels and plain safetensors uploads are skipped. radiance on its own lists every container. Repos tagged radiance are searched first, then untagged repos matching the name, so a container someone forgot to tag still turns up. Container quants: fp8, bf16, mxfp4, w4a8, i8g, iq8r, iq4r, int4/int5, iq1_s, or a bit width like 4bit. Drafters: mtp, dflash/df, dflash2/df2, dspark. Each .rad file gets a copy curl button for a resumable download.
